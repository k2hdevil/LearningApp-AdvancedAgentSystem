## 슬라이드 7. AWS Certification 레벨

- Foundational
- AWS 클라우드의 기본 사항을 이해하기 위한 지식 기반 자격증입니다. 이전 경험은 필요하지 않습니다.
- Associate
- 여러분의 지식과 기술을 보여주는 역할 기반 자격증. AWS 클라우드 또는 탄탄한 온프레미스 IT 관련 이전 경험이 권장됩니다.
- Professional
- 고급 기술과 지식을 검증하는 역할 기반 자격증입니다. 최소 2년의 AWS 클라우드 경험이 권장됩니다.
- Specialty
- 구체적인 주제에 중점을 둔 자격증입니다. 권장되는 경력 수준은 다양합니다.

> **수강생용 노트**
>
> AWS Certification은 업계에서 인정하는 보안 자격증으로 클라우드 전문 지식을 검증함으로써 신뢰와 확신을 쌓는 데 도움이 됩니다. 이 자격증은 조직에서 Amazon Web Services(AWS)를 사용하여 클라우드 이니셔티브를 이끌 수 있는 숙련된 전문가를 파악하는 데 도움이 됩니다.
>
> 슬라이드에는 현재 제공되는 AWS Certification이 나와 있습니다. AWS Certification을 취득하려면 감독관 참관 시험에서 합격 점수를 받아야 합니다. 역할 기반 자격증의 경우 AWS Cloud Services의 각 자격증 레벨에 권장되는 경험 수준은 다음과 같습니다.
> Professional: AWS 클라우드를 통한 솔루션 설계, 운영, 문제 해결 경험 2년
> Associate: AWS 클라우드를 통한 문제 해결 및 솔루션 구현 경험 1년
> Foundational: 기초 AWS 클라우드 경험 및 업계 지식 습득 경험 6개월
>
> Specialty 자격증은 특정 기술 분야에 중점을 두고 있습니다. Specialty 시험 응시에 권장되는 경험은 시험 가이드에 지정된 영역에서의 기술 경험입니다.
>
> AWS는 자격증 시험에서 다루는 모든 서비스 또는 기능의 목록을 게시하지 않습니다. 그러나 각 시험의 시험 가이드에는 시험에서 다루는 현재 주제 영역 및 목표가 나열되어 있습니다. 자세히 알아보고 시험 가이드와 기타 준비 자료를 복습하려면 AWS Certification 시험 준비(https://aws.amazon.com/certification/certification-prep/)를 참조하십시오.
>
> 이 정보는 2026년 1월 기준으로 작성되었습니다. 그러나 시험은 자주 업데이트되며 제공되는 시험과 각 시험의 테스트 항목에 관한 세부 정보는 변경될 수 있습니다. 최신 AWS Certification 시험 정보는 AWS Certification(https://aws.amazon.com/certification/)을 참조하십시오.
>
> 3년마다 자격증을 갱신(또는 재인증)해야 합니다. 자세한 내용은 AWS 자격증 갱신(https://aws.amazon.com/certification/recertification/)을 참조하십시오.

## 슬라이드 8. AWS Certification 시험 준비 단계

- 자신 있는 시험 준비
- 1단계
- 시험 및 시험 유형의 문제에 대해 알아봅니다.
- 2단계
- AWS Skill Builder에서 시험 토픽에 대해 알아봅니다.
- 3단계
- AWS Skill Builder에서 시험 준비 자료로 학습합니다.
- 4단계
- 공식 연습 시험으로 실전 시험 준비 상태를 확인합니다.
- 모든 AWS Certification 시험에 대해 알아봅니다.

> **수강생용 노트**
>
> 이 과정에는 AWS Certification 시험과 관련이 있을 수 있는 콘텐츠가 포함됩니다. 시험 준비를 계속하려면 핵심적인 다음 4개 단계를 따르십시오.
>
> 각 시험에 관한 자세한 내용을 보려면 QR 코드를 스캔하여 AWS Certification 시험 살펴보기(https://aws.amazon.com/certification/exams)를 참조하십시오.

## 슬라이드 9. AWS Certification 취득 준비: 1단계

- 시험 및 시험 유형의 문제에 대해 알아보기
- 시험 가이드를 검토합니다.
- AWS 온라인 학습 센터인 AWS Skill Builder에 액세스하려면 가입합니다.
- 등록하고 AWS Certification 공식 연습 문제 모음을 풀어봅니다.

> **수강생용 노트**
>
> 1단계는 시험 및 시험 유형의 문제에 대해 알아보는 것입니다.
>
> AWS Certification 시험 페이지에서 각 시험의 시험 안내서를 검토할 수 있습니다. 자세한 내용은 모든 AWS Certification 시험 살펴보기(https://aws.amazon.com/certification/exams)를 참조하십시오.
>
> 샘플 시험 문제를 보려면 AWS Skill Builder에 가입합니다. Skill Builder 내에서 Official Practice Question Set에 등록할 수 있습니다. 자세한 내용은 AWS Skill Builder: 수요가 많은 클라우드 기술을 구축하기 위한 학습 센터(https://explore.skillbuilder.aws/learn)를 참조하십시오.
>
> 실제 AWS Certification 시험에 나올 수 있는 문제와 동일한 프로세스에 따라 연습 세트의 문제가 생성됩니다. 여기에는 시험을 준비하는 데 도움이 되는 자세한 피드백과 권장 리소스가 포함되어 있습니다.

## 슬라이드 11. AWS Certification 취득 준비: 3단계

- AWS Skill Builder에서 시험 준비 자료로 학습
- AWS Skill Builder는 모든 도메인에 걸쳐 과정을 제공합니다.
- AWS Builder Lab에는 500개 이상의 자습형 실습(SPL)이 포함되어 있습니다.
- AWS Cloud Quest의 게임 방식 학습으로 AWS Certification 시험을 준비합니다.

> **수강생용 노트**
>
> 다음으로 AWS Skill Builder에서 시험 준비 과정을 수강할 수 있습니다. Skill Builder는 여러분의 지식에서 부족한 부분을 해결하는 데 사용할 수 있는 많은 리소스도 제공합니다.
>
> Skill Builder는 모든 영역의 교육 과정을 제공합니다. AWS Builder Lab에는 500개 이상의 자습형 실습(SPL)이 포함되어 있습니다. 그리고 게임을 플레이하여 AWS 서비스를 직접 경험하고 싶은 경우에는 AWS Cloud Quest를 시도해 볼 수 있습니다.
>
> 참고: 이러한 리소스 중 일부는 디지털 구독이 필요합니다.

## 슬라이드 12. AWS Certification 취득 준비: 4단계

- 실전 시험 준비 상태 확인
- 시험 스타일로 채점되는 AWS Certification 공식 연습 시험을 실시합니다.

> **수강생용 노트**
>
> 마지막으로, 공식 연습 시험에 응시하여 실전 시험 준비를 확인하십시오.
>
> 각 연습 시험에는 실제 시험과 동일한 수의 문제가 포함되어 있습니다. 연습 시험은 자격증 시험과 동일한 문제 스타일과 난이도에 같은 수준의 엄격함을 적용하여 연습을 진행합니다. 여기에는 시험 방식의 채점과 통과 또는 실패가 포함됩니다. 또한 각 문제의 선택 답안에 대한 피드백과 함께 핵심 주제에 대한 이해 심화를 도울 수 있는 권장 리소스가 함께 제공됩니다. 또한 제한 시간이 있고 시험이 끝난 후에만 정답이 공개되는 모의 시험에 응시하여 시험을 미리 경험해 볼 수 있습니다. 또는 제한 시간이 없는 시험이나 각 문제의 답을 제출할 때마다 정답이 공개되는 시험 등의 다른 옵션을 선택할 수도 있습니다.
